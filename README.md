# 🎮 Game Discovery Tool

Find your next game based on how you're feeling and not just the genre.

## What It Does

Instead of browsing endless lists, pick a mood and get a curated set of highly rated games that match your vibe. Whether you want something cozy and relaxing or intense and action packed, the tool does the filtering for you.

## Moods

| Mood | What You Get |
|------|-------------|
| 🌿 Cozy | Relaxing, feel-good games |
| 🔥 Intense | High-octane shooters and action |
| 🎨 Indie | Highly-rated indie gems |
| 👥 Multiplayer | Co-op and competitive games |
| 📖 Story | Narrative-driven RPGs |

## Tech Stack

- **Next.js 16** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **IGDB API** (via Twitch)
